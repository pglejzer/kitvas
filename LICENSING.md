## What you make with kitvas

The licenses of kitvas do not cover the interface code you make with it: your drafts, the code a hand-off writes into your project and the layers it sends to Figma. Only the parts of kitvas that such code contains are covered, each by its own license above: the kitvas UI kit by the MIT License, anything else, for example the runtime inside a built prototype, by the PolyForm Shield License.
